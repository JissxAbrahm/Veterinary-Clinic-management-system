# Veterinary Clinic Management System

A simple Veterinary Clinic Management System developed using PHP, HTML and MySQL.

## Technologies Used
- HTML
- PHP
- MySQL / MariaDB
- WAMP Server
- phpMyAdmin

## Database Setup
1. Open phpMyAdmin.
2. Create a database named `vet_db`.
3. Select the database.
4. Import the `database.sql` file.

## Installation
1. Install WAMP Server (64-bit).
2. Copy the `vet_clinic` folder into `C:\wamp64\www\`.
3. Start Apache and MySQL/MariaDB.
4. Verify database credentials in `db.php`.
5. Open your browser.

## Run Project

http://localhost/vet_clinic/

## Features
- Pet information management
- Veterinarian information
- Visit information management
- Combined visit reports using SQL INNER JOIN
